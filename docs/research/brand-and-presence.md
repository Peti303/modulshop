## Mi érhető el bejelentkezés nélkül, és mihez kell Meta Graph API

**Bejelentkezés nélkül elérhető:** a FB-oldal neve és követőszáma (Page Plugin), az IG-profil követő-, követés- és bejegyzésszáma (meta-leírás), a teljes YouTube-csatorna, az Onlinepénztárca és a saját ShopRenter-vélemények.

**Meta Graph API (vagy bejelentkezett oldaladmin) szükséges ezekhez:**
- FB-oldal **ajánlásai/értékelései**: `GET /{page-id}/ratings`. Kell hozzá egy Page Access Token, amelyet az oldal adminja ad ki, valamint a `pages_read_user_content` és a `pages_show_list` jogosultság. Szöveg, szerző, dátum és `recommendation_type` kérhető le.
- FB-oldal adatai: `GET /{page-id}?fields=name,about,category,fan_count,followers_count,overall_star_rating,rating_count,link,location,website`. A `pages_read_engagement` jogosultság kell hozzá.
- FB-bejegyzések: `GET /{page-id}/posts` a weboldali feed-beágyazáshoz.
- Instagram (csak üzleti vagy alkotói fiók, a FB-oldalhoz kapcsolva): `GET /{ig-user-id}?fields=username,name,biography,followers_count,media_count,profile_picture_url`, valamint `GET /{ig-user-id}/media`. Az `instagram_basic` és a `pages_show_list` jogosultság kell hozzá. Előbb meg kell erősíteni, hogy a @modulshop valóban a cég fiókja, és üzleti fiókká kell alakítani.
- Egy saját oldal tartalmának olvasásához nem kell App Review, ha az admin a fejlesztői app tesztelőjeként vagy adminjaként szerepel. Éles, több felhasználós apphoz App Review kell.

**Google-értékelésekhez:** a Google Business Profile API (`accounts.locations.reviews.list`) a profil tulajdonosának OAuth-hozzáférésével használható, vagy a Places API (legfeljebb 5 vélemény, Google-attribúcióval).
